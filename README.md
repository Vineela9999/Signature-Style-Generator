# ✍️ Signature Style Generator

A Python-based web application built with **Streamlit** and **Pillow** that allows users to create, customize, preview, and download digital signatures.

## 🚀 Live Demo

[Try Signature Style Generator](https://signature-style-generator-3fkeyw2kwyixvfc2bbx42y.streamlit.app/)

## ✨ Features

- Generate multiple signature designs.
- Choose between simple and stylish signatures.
- Customize signature colors.
- Select transparent or white backgrounds.
- Upload custom TTF/OTF fonts.
- Add decorative underlines.
- Download signatures as PNG images.
- Choose personal or professional signature purposes.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pillow (PIL)
- Git and GitHub

## 💻 Run Locally

1. Clone the repository:

   `git clone https://github.com/Vineela9999/Signature-Style-Generator.git`

2. Navigate to the project folder:

   `cd Signature-Style-Generator`

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`
