# Signature Style Generator

A Python-based web application built using Streamlit and Pillow that allows users to generate customized digital signatures.

## Features
- Generate simple and stylish signatures.
- Choose different signature styles.
- Customize signature colors.
- Select personal or professional signature purposes.
- Download signatures as PNG images.
- Choose transparent or white backgrounds.
- Upload custom TTF/OTF fonts.

## Technologies Used
- Python
- Streamlit
- Pillow

## How to Run

1. Clone the repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `python -m streamlit run app.py`

## Project Purpose
This project demonstrates Python programming, image processing, and interactive web application development.
